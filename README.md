# Mohamed Dhia Bargougui

Hi, I'm Dhia, a cybersecurity and AI graduate based in Sfax, Tunisia. I work at the intersection of AI and security: defending SOC environments and securing LLM and multi-agent systems.

## Focus Areas

### AI & LLM Security
- Securing multi-agent LLM systems with blockchain-enforced access control (Hyperledger Fabric ABAC) and immutable audit trails
- Red team assessment of agent orchestration and access-control layers
- AI security frameworks: NIST AI RMF, MITRE ATLAS, OWASP ML Top 10, OWASP Top 10 for LLM Applications

### Blue Team & Detection
- SOC threat hunting and incident response with Splunk, mapped to MITRE ATT&CK
- Vulnerability intelligence with NVD, CISA KEV and EPSS
- Writing incident response reports and playbooks
